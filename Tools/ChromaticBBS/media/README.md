# Retained performances

Voice, music and SFX use one measured browser mixer. These recordings are
optional sidecars; the HTML embeds art and game code, not these audio bytes.
Copy the `media/` folder beside `index.html`, or unpack the separate media
archive there. `manifest.json` records exact byte counts and SHA-256 hashes.
The player refuses a track whose bytes differ. It never calls a missing
recording by a familiar name.

JazzSauce is a stream-copy of Friken’s publicly streamable SoundCloud AAC
performance. It is not a recovered original MP3 and was not re-encoded.
Its observed public permalink is retained in the manifest. Epic II was
recovered from the public Masha 1 response. Catchy Cat and Bang Non And On
are retained project exports. Epic I was not found among the 59 observed
public tracks or in this checkout. Its absence remains explicit.

The original project artwork and performances retain their existing rights.
Publication alone does not create a new licence. No signed streaming URL,
access credential, SoundCloud session data or private chat belongs here.

`human-salvage-frame.png` is a generated original production framing asset.
It is embedded by the builder; music remains separately portable.
