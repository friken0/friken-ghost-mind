## Sound and art portability

The builder embeds code, original resident paintings, shaders and the reusable
transparent framing PNG. Actual music is in the **media sidecars**. Retain
`chromatic-media.zip` beside the source kit; extract it beside `index.html`.
The manifest verifies exact recording bytes before decode. JazzSauce is an
AAC stream-copy of Friken’s public SoundCloud performance. Epic II is recovered
from Masha 1; Catchy Cat and Bang Non And On are retained originals. Epic I
has not been found and is not substituted under its name.

One mixer supplies measured bass/mid/air/attack to the face, SDF and rose.
Neural voices normalize toward the same active RMS. Music plays at 55% of
that reference, 10% during the modem. Ghost mouth follows Ghost PCM only.
Default Kokoro speech uses George for Ghost and Heart for the female narrator;
first use downloads roughly 100 MB of pinned runtime/model dependencies.
Inference is local. Dial starts voice loading during the modem; the voice
button reports loading, preparing, speaking, paused or retry. Tab return
resumes unfinished speech. Mute or a new choice cancels that resume. A stuck
preparation expires after 120 seconds; Read scene retries it. Keep runtime,
weights and licences separately for fully offline speech. VOICE CAST exposes explicit host/device alternatives.

`?check` isolates test storage; it no longer mutes TTS. `?qaAudio=silent`
is the explicit automated mute. Waiting captions stay readable while local
speech generates. Playback reveals terminal ink; Show full text keeps audio.

## Saves, public memory and the full game

Every accepted choice saves in a private local vault when storage permits.
Export the archive to carry all retained runs, their complete choice journals
and exact checkpoints. Export canon alongside it. Two MiB is the current
vault limit; quota failure preserves old bytes and exposes the new seed.
Private saves never enter a public news projection automatically.

The public repository accepts reviewed GitHub submissions. Anonymous play
requires no account; public intake requires GitHub authentication. Scores
are player-reported and unverified. Publication has distinct review/consent
steps; a composed issue is not a submitted or admitted record.

The full Unity importer is **not implemented**. The runbook specifies an
opt-in archive/pairing bridge, idempotent private imports, conflict preview,
canon selection and source-backed Ghost memory. Buying the game cannot
silently expose browser cookies or private chats. Browser scores must not
mint canonical currency or skills. The portable archive is the current bridge
material; no completed automatic sync is claimed.
